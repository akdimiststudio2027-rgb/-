# استوديو أكاديمي V7

نظام إدارة لاستوديو أكاديمي مبني بـ PHP + MySQL.

## التشغيل المحلي
1. ضع مجلد `academic-studio` داخل `C:\xampp\htdocs\`.
2. شغل Apache و MySQL من XAMPP.
3. إذا كانت قاعدة `academic_studio` الحالية تعمل مع V6، لا تحذفها ولا تستخدم setup.php.
4. افتح `http://localhost/academic-studio/login.php`.
5. الحساب الافتراضي: `admin@akadimi.local` / `Admin@123`.

## الأقسام
لوحة التحكم، الأساتذة، الجدول الأسبوعي والشهري، الحسابات والمالية، التقارير، المستخدمون والصلاحيات، الإعدادات والنسخ الاحتياطي.

## ملاحظة
`setup.php` مخصص للتهيئة من الصفر فقط ويحذف قاعدة البيانات عند تأكيد RESET. لا تستخدمه على قاعدة تحتوي بيانات مهمة.

## iPhone / PWA
تمت إضافة دعم PWA محسّن للآيفون، مع أيقونات التطبيق وبيانات manifest ووسم Apple. راجع `IPHONE_INSTALL.md` لطريقة التثبيت.
